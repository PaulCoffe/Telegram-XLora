## История и контекст проекта: TelegaMesh (Telegram-XLora)

## Описание проекта
Форк Telegram X с интеграцией LoRa Mesh-сетей (MeshCore) в качестве резервного офлайн-канала связи. 
Цель проекта — обеспечить надежный обмен сообщениями при отсутствии интернета с автоматической синхронизацией сообщений с Telegram Cloud при восстановлении связи.

## Текущий статус и последние события
- **Интеграция LoRa Mesh**: Выполнена базовая интеграция протокола в Telegram X. Настроен транспортный переключатель между Cloud и Mesh, а также ограничение на текстовые сообщения в режиме Mesh.
- **Исправление логики Mesh**: Исправлен критический баг в `MeshManager`, который приводил к пересозданию фрагментатора сообщений при каждом пакете. Теперь сообщения > 200 байт корректно собираются воедино.
- **Стабилизация CI/CD**: Внедрен надежный механизм клонирования сабмодулей в GitHub Actions, обходящий ошибки некорректно настроенного дерева Git в репозитории.
- **Нативные патчи**: В процесс сборки интегрированы обязательные патчи для библиотек `opus` и `androidx-media`, что устранило основные причины `Native Crash` (падений приложения) при работе с медиа.
- **Временная фиксация версий**: Из-за устаревшей версии `tdlib` в текущем форке (2022 год) было принято решение временно «заморозить» вспомогательные модули `vkryl/*` в состоянии на ноябрь 2022 г. Это позволило получить рабочий APK как временное решение.
- **Цель на будущее — PR в основной репозиторий**: Конечной целью проекта является достижение полной совместимости с оригинальным репозиторием `TGX-Android/Telegram-X` для возможности подачи Pull Request.

## Инструкция по подключению к GitHub (через gh CLI)
Для настройки доступа агента к репозиторию использовались следующие команды:
1. Авторизация через токен (если требуется): `gh auth login`
2. Проверка статуса авторизации: `gh auth status`
3. Клонирование репозитория (уже выполнено): `gh repo clone PaulCoffe/Telegram-XLora`
4. Просмотр статуса CI/CD: `gh run list` и `gh run view <ID> --log`
Для корректной работы с Git через SSH в среде агента используется SSH-ключ, привязанный к аккаунту GitHub.
